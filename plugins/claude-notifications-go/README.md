# Agent Notifications

Desktop alerts for Claude Code task completion and requests for input, with sounds, click-to-focus, and optional webhooks on macOS, Linux, and Windows. The project also supports Codex CLI, OpenCode, Gemini CLI, Cursor CLI, and Qoder.

This directory is a catalog definition only. It does not bundle the notification runtime, hooks, or installer and is not registered in this repository's marketplace. Install the maintained plugin from the [upstream project](https://github.com/777genius/agent-notifications#readme) using its documented setup flow.

The legacy Claude plugin name `claude-notifications-go` is retained for compatibility. See the [upstream identity policy](https://github.com/777genius/agent-notifications/blob/main/docs/CLAUDE_PLUGIN_IDENTITY.md).
