# Hermes Tweet

Hermes Tweet is a native Hermes Agent plugin for X/Twitter automation through Xquik.
It provides read-first workflows and keeps private or write-like endpoints behind
an explicit action gate.

Install from the source repository:

```bash
hermes plugins install Xquik-dev/hermes-tweet --enable
```

For full setup and safety guidance, see the
[Hermes Tweet repository](https://github.com/Xquik-dev/hermes-tweet).
